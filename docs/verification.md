## Что покрыто

Модульные проверки: точная сумма, отрицательные/дробные/нечисловые значения, верхние границы, итоговое переполнение, количество строк, неверная дата; реальный локальный HTTP-обмен адаптера с тестовым сервером, корректный и некорректный JSON, отказ провайдера, денежные условия, отсутствие ключа и удаление очевидных телефонов/email.

PostgreSQL: чтение/изменение/публикация/клонирование/ссылки/ответы чужой мастерской запрещены; пользовательский итог игнорируется; публичный allowlist; один победитель конкурентного решения; вопрос блокирует решение, ответ возвращает ожидание; черновик не меняет активную версию; после замены сохраняются старые цены и решение; истечение и отзыв запрещают новые ответы и не уничтожают прежнее решение; перевыпуск отзывает старый токен; гонка публикации и ответа; UNIQUE/CHECK/immutability constraints; UTC независимо от исходного часового пояса PostgreSQL.

Браузер: регистрация → ручной ввод без AI → предпросмотр без публикации → сохранение → публикация → отдельное неавторизованное окно клиента → ознакомление с итогом и согласование → проверка результата владельцем → новая цена и версия → сохранённое старое решение → вопрос → ответ мастера → возврат действий клиенту → отказ. Дополнительно: поиск, пустая выдача, длинные названия, ошибка пароля, вход/выход, защита ухода с несохранёнными изменениями. Проверки HTTP подтверждают 401/404/403, входные границы, недоступность ненастроенного AI, заголовки, allowlist и 429.

Вход, редактор, кабинет и клиентская страница проверены при 390, 768 и 1440 px на отсутствие горизонтальной прокрутки. Девять снимков кабинета/редактора/клиентской страницы просмотрены визуально. Текстовые статусы, подписи, focus-visible и reduced-motion реализованы; полный аудит screen reader/доступности не проводился.

## Исправления в ходе проверки

- Первый интеграционный прогон выявил unhandled rejection в тесте чужих операций: асинхронные отказы ожидались слишком поздно. Тест исправлен, повторный прогон чистый.
- Браузерный прогон выявил неявное имя поля пароля из-за подсказки внутри label. Добавлены точное доступное имя и aria-describedby.
- После клонирования могла оставаться старая ссылка в интерфейсе новой версии. Поле очищается при клонировании, публикации и перевыпуске.
- E2E ожидал ответ клиента сразу после клика мастера, до завершения запроса. Теперь ожидает сохранённый ответ на стороне мастера перед обновлением клиента.
- Дополнительная проверка несохранённых изменений сначала использовала декоративную иконку в accessible name. Локатор исправлен на название действия, предупреждение о потере текста проверено.
- Часовой пояс PostgreSQL первоначально наследовался от Windows; соединения приложения теперь устанавливают UTC, это подтверждено отдельным тестом. Вымышленные демозаписи начального наполнения приведены к UTC.
- Workshop перенесён из ленивого создания при чтении в database trigger регистрации: служебные GET не изменяют бизнес-данные.
- Обновлены доступные исправленные транзитивные зависимости deepmerge-ts/mysql2. Непатченая dev-цепочка braces оставлена явно отмеченной; принудительное понижение Next/Prisma не применялось.

Сообщение pg о deprecated concurrent client.query исходит из Prisma pg adapter; проверенные транзакции завершились корректно, pg 9 не используется. Оно не содержит токенов или заметок. Docker volume-перезапуск и качество настоящей AI-модели остаются непроверенными.
