PostgreSQL: PostgreSQL License. Локальные серверные бинарники загружены из официального EDB-архива; не входят в Git. Docker image postgres:17 — официальный образ, Docker запуск здесь не выполнялся.

Внешние сервисы: Exa использован для исследования официальных материалов. Опциональный OpenAI-совместимый API подключается только настройками владельца; его тарифы и условия определяются выбранным провайдером. Сторонняя аналитика, изображения и внешние шрифты не подключены.

Платных развёртываний нет. При первоначальном подборе AI предпринимался запрос к платной модели OpenRouter; наблюдался HTTP 402. Сверка фактических расходов в кабинете провайдера не проводилась, поэтому нулевой расход или согласованный платный запуск не заявляются. Последующие проверки используют бесплатную модель. Теперь внешняя платная модель блокируется до HTTP-запроса без AI_ALLOW_PAID_MODELS=true; включать его можно только после согласования расходов. В рамках сверки с PDF платных запросов не выполнялось. В приложении нет стороннего брендированного медиаконтента.

Материалы сдачи: PowerPoint создан Artifact Tool, PDF подготовлен ReportLab (BSD). Первое видео использовало системную озвучку Windows; новая версия записана из работающего приложения и смонтирована FFmpeg с нейросетевым русским голосом `ru-RU-SvetlanaNeural` через Microsoft Edge online speech / edge-tts. Голос синтетический; имитация конкретного человека не запрашивалась. Инструменты подготовки видео не нужны для запуска MVP. Снимки и запись показывают собственный интерфейс с вымышленными данными, сторонние фотографии и иллюстрации не использованы.
